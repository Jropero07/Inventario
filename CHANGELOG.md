# Historial de versiones

| Versión | Cambios principales |
|---|---|
| v19 | Corrección del flujo de movimientos (referencia `id` inexistente); Firestore deja de bloquear operaciones. |
| v20–v22 | Usuarios propios con roles, permisos personalizados, clave temporal/fija y recuperación de contraseña. |
| v23–v24 | Usuario en cada movimiento, bitácora de accesos, bloqueo por intentos, cierre por inactividad, papelera. |
| v25–v26 | Orden de Requerimiento en el formato oficial GA-LO-CO01 (Word diligenciado y PDF). |
| v27 | Exportación inteligente (solo columnas útiles) en PDF, Excel y nuevo CSV. |
| v28 | Desplegable de artículos por espacio; rotación por artículo por código. |
| v29–v30 | Reversión de salidas con lugar de retorno; todo el texto en MAYÚSCULAS. |
| v31–v34 | Vista móvil en tarjetas, ficha "Ver" y acciones simplificadas. |
| v35–v36 | Sesión anónima de Firebase y reglas de seguridad; bitácora resumida. |
| v37–v38 | Salida repartida en varios destinos. |
| v39 | Logo institucional. |
| v40–v41 | Hoja de vida en Realtime Database, aviso antes de cerrar sesión, mantenimiento preventivo con pestaña y exportación. |
| v42–v43 | Modo claro/oscuro automático con botón; centrado de botones. |
| v44 | PWA instalable, aviso de conexión, escanear y abrir ficha, ordenar y paginar tablas, detalle de cambios, panel de inicio. |
| v45 | README y documentación del proyecto. |
